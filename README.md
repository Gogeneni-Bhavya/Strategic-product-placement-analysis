# Strategic Product Placement Analysis

## Project Overview

Strategic Product Placement Analysis is a retail analytics and data visualization project developed to analyze how product placement strategies influence sales performance.

The project uses Tableau to transform retail data into interactive visual insights. A Flask and Bootstrap-based web application is used to integrate and present the Tableau Dashboard and Tableau Story in a simple project portfolio.

This project was completed as an group implementation.

---

## Project Objective

The main objective of this project is to analyze retail product placement and identify factors that influence sales performance.

The analysis focuses on:

- Product category performance
- Product positioning
- Consumer demographics
- Sales volume
- Seasonal sales trends
- Promotions
- Competitor pricing
- Foot traffic

The project helps present retail data in an interactive and understandable visual format for data-driven decision-making.

## Project Outcome

The project successfully transforms retail product placement data into interactive Tableau visualizations.

The Dashboard enables users to analyze product categories, sales volume, consumer demographics, product positioning, pricing, promotions, and foot traffic.

The Tableau Story presents important analytical findings in a structured visual format.

The Flask web application provides a centralized interface for accessing the Dashboard, Story, and project information.
